# Transport prop meshes

These OBJ files are deterministic, project-owned procedural assets for the
MuJoCo transport scene. They are generated by:

```bash
python scripts/generate_transport_prop_meshes.py
```

- `*_visual.obj`: smooth render geometry (`contype=0`, `conaffinity=0`), including
  separate apple stem/leaf, banana end caps, orange calyx and pear stem meshes.
- `*_collision*.obj`: low-poly convex collision geometry, hidden in geom group 3.
- The banana uses five overlapping convex pieces so collision follows its curve.
  A single concave mesh is not used because MuJoCo collides against a convex hull.
- Apple, orange and pear each use one low-poly convex collision hull.

Coordinates are metres in each free body's local frame. The generated assets
are covered by `src/rby1_description/LICENSE` (MIT).
